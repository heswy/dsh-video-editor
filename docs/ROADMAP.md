# 阶段路线

更新：2026-10-17。依据用户确认的 v0.3 产品方向；本文件是规划，不自动放行实施。任务范围和交付基线以实际下发指南为准。

| 阶段 | 目标 | 状态与验收关口 |
|---|---|---|
| P0 宿主壳 | 原生 Vedio Editor 导航、主面板、会话保留、启停清理 | 核心真机证据通过；未测项保留于对应验收记录 |
| P1 引擎可行性 | 可编辑工程、保存重开、seek、真实 MP4、取消 | 受控本机范围通过 |
| P2 Host/通信 | UI/Tool 共用操作、revision、可靠子进程、产物服务 | 0.2.1 已安装；0.2.2 取消/时序修复通过独立本地复核，P2-007 交付门禁待修，未安装；不把旧 UI 视为最终产品 |
| P3-001/003 多 Scene | 工程创建、模板生成、Scene 操作、三方合并、历史/撤销 | 已在受控范围验收；schema 缺口列入 P3-004 |
| P3-004 预览基础 | 固定 revision 快照、schema、生命周期清理 | 已下发 p1-engine，待交付；用户删场景卡片不影响此基础 |
| P3-005 新编辑工作区 | 大画布播放/定位/直接选中与就地编辑、右侧 AI 常驻 | 正式指南待编写；先核对原生 Session/Conversation/模型接入，再冻结阶段契约；无底部场景卡片带 |
| P3-006 创作接线 | 工程与多创作会话关联、历史续聊、模型选择、素材导入/引用、AI 创建/局部修改、人工冲突处理 | 规划；用户素材为核心能力，不整体推迟到 P4。可按依赖拆任务，格式逐项真实验收 |
| P3-007 端到端样例 | 一句话生成 15s 多 Scene → 直接编辑 → AI 保留人工变更续改 → 重开 → MP4 | 尚未完成；不是用固定 fixture 代替真实 AI 请求 |
| P4 打磨与分发 | 性能、素材格式扩展、兼容矩阵、安装升级恢复、发布 | 未开始 |

原生对话接入调查可在快照交付前独立准备，但调查结果和设计示意不代表可安装功能。当前素材抽屉默认收起，音频/视频按解码、预览、导出链逐项开放；完整专业 NLE、云渲染、任意代码沙箱另立范围。
