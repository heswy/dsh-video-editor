# dsh-video-editor 产品范围

dsh-video-editor 是 DeepSeek Harness 内的 AI 视频创作与剪辑插件。右侧复用宿主原生对话、模型与权限，左侧自动预览同一工程的新版本。

## 1.0.0

- 对话生成与持续修改；工程引用、会话历史与多工程恢复。
- 图片、视频、音频导入；素材归属于工程。
- 多视频/音频轨，移动、裁剪、拆分、复制、排序与吸附。
- 连续缩略图、真实音频波形、视频原声显示与手动分离音频。
- 轨道画面/声音开关、删除确认、共享撤销/重做。
- AI 本地生成结构化音频后直接上轨；用户音频上传进入素材。
- 插件设置页配置音乐模型（同步/异步兼容协议、Base URL、远端模型 ID、API Key、默认模型与连接测试）与追加系统提示词；全部在页面完成，不要求编辑任何配置文件。
- 时间线框选任意时间范围并注册为原生 `@`「当前时间范围」引用；结合剧情描述由对话生成器乐提示词，调用已配置模型生成配乐并严格覆盖选区上轨。
- 自动工程时长、播放与跳转、H264/AAC MP4 导出。
- 插件版本检查与用户主动安装更新。

## 边界

画布内对象直接编辑延期；供应商凭据与提示词只经设置页写入 Host 内部持久化，聊天 Tool 不得读取或配置；不承诺任意代码的系统级沙箱。工程和素材保存在稳定数据根，默认 `~/Movies/DSH Video`。

当前实测平台为 macOS Apple Silicon。发行依赖 DSH、Node.js 22+、FFmpeg/ffprobe 与 Chrome；其他平台和缺依赖场景须另行验证。版本事实读 [STATUS](../STATUS.md)。
