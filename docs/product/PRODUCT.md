# 产品约定

更新：2026-10-17。

## 已确认的交互

用户参考：[原始截图](references/mode-switch-request.png)。主内容区域顶部提供两段切换，左侧「普通」，右侧「视频」。普通呈现正常 DSH；点视频进入本插件编辑工作区，再点普通可返回。

- 顶部切换不等同于已有的「标准模式」Agent preset 选择器。
- 不覆盖现有会话列表、模型或权限设置；普通模式状态继续保留。
- 视频模式保存当前工程、Scene、选择与播放位置；反复切换不丢失。
- 顶部准确挂载点、布局及窗口拖拽区域冲突由 P0 实测；不能因为 API 尚未确认擅自改成侧栏专属入口。
- 若没有合适扩展点，先报告契约和可行替代，由主会话与用户决定。禁止未经确认 fork/修改宿主实现位置。

## 核心创作闭环

Brief + Logo/截图 → AI 建立多 Scene 可编辑工程 → 预览 → 用户直接修改 → AI 继续编辑且保留人工变更 → 保存重开 → 导出 MP4。

第一条完整产品样例：15 秒产品发布片，3–4 个 Scene；支持选中文字/图片、改标题和基础布局/时序、修改指定 Scene、基础音轨及撤销/重做。

编辑能力分级：Scene 可交给 AI 重写；受支持 DOM 元素结构化修改；Canvas/WebGL 内部对象先只承诺参数化或代码编辑。不要宣传任意程序化画面都能逐对象拖拽。

## 初期范围

- 宿主目标：本机 Desktop 0.2.0-rc.2，升级另做兼容任务。
- 引擎候选：优先 HyperFrames 原生工程/SDK/渲染入口，尚未通过集成验证，不提前冻结版本和运行进程形态。
- MVP 不含：完整传统 NLE、Whisper 必选、复杂字幕、3D 逐对象编辑、多渲染后端、云渲染和专业混音。
- P0 是宿主接入验证；P0 页面不是完整视频编辑器，也不能假装已实现生成/导出。
