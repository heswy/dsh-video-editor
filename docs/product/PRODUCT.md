# 产品约定

更新：2026-10-17。

## 已确认的交互

2026-10-17 最新用户要求替代原顶部切换方案：左侧宿主导航中，**「上下文洞察」之后、「工作区」分组之前**增加单一入口 **Vedio Editor**，配简洁精致的细线条视频图标。文字按用户指定拼写，不自行改为 Video Editor。

2026-10-17 用户新增编辑器画布要求（当前 0.2.x 未实现）：

- **画布可直接点选对象**：点击画面中某个元素即选中它，右侧「目标」同步切换。
- **选中态可视**：右侧目标被选中时，画布上对应对象必须显示选中态（细描边/选择框）；切换目标时画布选中态跟随；选中框只属于编辑 UI，不进入导出内容。
- 该能力与「播放/暂停/seek」同属**实时预览画布**（A1：sandbox iframe + 受控工程快照 + 固定 HyperFrames runtime），需 engine snapshot + Host 精确资产路由；实现排在 P3-004（AI 创作 UI）之前，因为对象上下文/选中态是 AI 编辑闭环的一部分。
- 未接入前，静态 PNG 画布不伪装可点选；右侧目标下拉继续作为唯一选中入口并明确标注当前对象。

- 移除普通模式和视频模式的顶部「普通｜视频」胶囊；不再追求顶部居中。
- 点击侧栏入口进入视频工作区；选中态来自宿主 activePanel。保留返回原会话的便捷操作，不改变 Session、模型、权限或草稿。
- 使用受支持的原生导航 Slot。精确位置须核对本机契约；位置不支持时报告实际限制，禁止覆盖宿主 DOM 或猜坐标。
- 视频模式保留工程、Scene、选择与播放位置；反复切换不丢失。
- 界面简洁、克制、信息层级清楚。精致感来自留白、比例、排版、图标和细致反馈；玻璃与动效从属于内容。
- 不在产品页面展示开发阶段、未来功能、接入说明或重复空状态。无工程时只保留一句状态及真实可用的必要操作；不加尚未实现的创建/导出按钮。具体约束见设计规划。

原顶部方案及 P0-A 靠左选择属于历史已验证方案；历史截图与验收证据保留，不再作为新 UI 的目标。

## 核心创作闭环

Brief + Logo/截图 → AI 建立多 Scene 可编辑工程 → 预览 → 用户直接修改 → AI 继续编辑且保留人工变更 → 保存重开 → 导出 MP4。

第一条完整产品样例：15 秒产品发布片，3–4 个 Scene；支持选中文字/图片、改标题和基础布局/时序、修改指定 Scene、基础音轨及撤销/重做。

编辑能力分级：Scene 可交给 AI 重写；受支持 DOM 元素结构化修改；Canvas/WebGL 内部对象先只承诺参数化或代码编辑。不要宣传任意程序化画面都能逐对象拖拽。

## 初期范围

视觉偏好（用户已确认）：优美、精致、优雅，考虑液态玻璃，动效可以丰富。具体材质、布局和动效见 [前端设计规划](../design/FRONTEND-DESIGN.md)，当前为待真页面验证的方向草案，不自动扩大 P0 的实现范围。

- 宿主目标：本机实际 Desktop **0.2.1-rc.1**（D013；0.2.0-rc.2 仅历史证据），升级另做兼容任务。
- 引擎：HyperFrames 0.8.167 + 独立 Node worker 已在受控本机范围验收；P2 Host 接入在分支上待复审修复（R1–R4），未通过真实宿主内引擎集成或任意生成代码隔离验收。
- MVP 不含：完整传统 NLE、Whisper 必选、复杂字幕、3D 逐对象编辑、多渲染后端、云渲染和专业混音。
- P0 是宿主接入验证；P0 页面不是完整视频编辑器，也不能假装已实现生成/导出。
