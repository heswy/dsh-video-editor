# DSH Video 1.0.0 验收矩阵（V1.0-ACCEPTANCE）

日期：2026-10-21（Asia/Shanghai）。状态：**验收计划，等待“开始”后逐里程碑执行**。
配套：[V1.0-PLAN.md](V1.0-PLAN.md)、[V1.0-DEVELOPMENT-GUIDE.md](V1.0-DEVELOPMENT-GUIDE.md)、[方案](../research/2026-10-21-v1-major-version-proposal.md)。

## 0. 使用方式与原则

- **每个里程碑 = 一个候选 `1.0.0-alpha.N` 固定 staging + 一次用户真机验收**。验收不通过不进下一里程碑。
- 用户执行操作、Lead 记录结果；开发会话不得代填“通过”。**未测项必须显式写“未测”，不能省略**。
- 验收证据：版本/staging/INTEGRITY sha256、操作步骤、实际结果、脱敏截图/文件路径、失败复现步骤。
- 分层结论分开写：**自动门禁（L1–L3）≠ 真机（L4）≠ 真实模型/长片（L5）**；组件浏览器/mock 不能冒充真机。
- 每次验收前由 Lead 给出「安装信息卡」：staging 路径、INTEGRITY、版本、安装步骤、回滚入口、本次清单。

### 安装信息卡模板

```md
【DSH Video 1.0 / alpha.N 验收卡】
- staging：artifacts/p2-b/staging-v1.0.0-alpha.N-<sha8>
- INTEGRITY sha256：<hash>
- bundle 版本：1.0.0-alpha.N；engine：0.5.0
- 安装：Plugins → Add plugin（link 上述 bundle）→ Install → Enable now →（如 client 变化）重启
- 已自动通过：L1/L2 数字 + L3 链（chain/preview/engine）
- 本次待你验收：<清单编号>
- 回滚：重装 staging-alpha11-51b95dc/bundle（0.3.0-alpha.11）
```

## 2. 回归清单（每个 alpha 必跑）

- 对话首轮生成 → 左侧自动出现可播作品；
- 续改一轮 → 同工程更新、旧画面保留、失败可恢复；
- 导出 5s 工程 → 下载成功；
- 作品名内联重命名（revision 不变）；
- 右栏拖拽宽度/双击恢复/窄窗堆叠；
- 点击对话内 fileLink 图片 → 插件内 overlay，不弹 sidebarRight；
- 插件禁用/启用不丢工程；退出/重启不丢工程。

> 以上 0.3 行为由 v0.3 验收覆盖，1.0 的每个候选至少抽 3 项回归（M6 全量）。

## 3. 数据迁移演练（M1、M6 各一次）

1. **备份**：对 `artifacts/p2-b/staging-alpha11-51b95dc` 下用户工程与数据根做双备份（`ditto` 到另一磁盘/目录）；记录大小与摘要。
2. **迁移**：安装 v1 候选 → 首次启动执行迁移 → 检查 `migration.json`、工程数、每个工程 revision/时间线/素材数。
3. **校验**：抽查 2 个工程打开、播放、导出；对比迁移前后抽帧（SSIM≥0.98）与时长/分辨率。
4. **失败注入**：模拟迁移中断/权限不足 → 应可重试、不丢源数据、不阻塞启动。
5. **回滚**：重装 alpha.11 → 旧数据仍可打开；记录结论。

**通过标准**：旧工程 100% 可见、可打开；无静默删除；失败可恢复；回滚可用。

## 7. 已知限制（1.0.0 发布说明草案）

- 仅 30fps CFR；29.97/VFR 源导入转代理；4K/HEVC/60fps 未原生支持（v1.1）。
- 无 WebAudio 程序化音频合成；音频只做轨/音量/淡入淡出/速度，无 EQ/压缩/ducking 自动化。
- 不支持声音克隆、多语言配音、自动字幕。
- 无云同步/多用户协同；工程在本机数据根。
- 生成音频依赖用户配置的第三方 provider（千问云试点）与网络；本地 `say` 仅 macOS。
- 宿主内部 API（@ 引用）随 DSH 版本变化可能降级为插件内引用。
- 非 darwin 平台行为未真机验证（窗口控制区/leading）。
