# 引用与资源面板优化（待评审，不合码）

2026-10-23 用户要求统一修复引用入口、浮层边界、信息层级、刷新位置、点击外部关闭及左侧素材/音频面板。明确要求先不合码。基线 origin/main `c66ed7b`；独立分支 `codex/panel-design`，复用干净隔离 worktree，单写入者。

## 根因与实现

- 引用原为 AI 消息前的普通流式区域；改为 AI 标题工具区中的图标＋文字入口，面板绝对定位在其下，不挤压消息。与创作历史入口互斥。
- 标题的 space-between 曾把三个子元素均匀拉开；刷新和关闭组成右侧操作组。
- 三类面板共用实底、清晰边框、双层阴影、12px 圆角和统一密度。素材和音频覆盖 bottom:auto，按内容收缩并限制最大高度，去掉贯穿画布/轨道的大面积空白。
- 引用名称为主行，类型/时间/轨道为次行，缩短帮助文本；自定义区间默认折叠，选中后才显示可复制标记。搜索、分页、失效引用校验和错误保留。
- 使用面板自身 ref 的共享 dismissal hook：外部 pointerdown 关闭，内部操作及自身入口不误关闭；全局 Escape 关闭并回焦入口，引用打开后聚焦搜索。监听在卸载时清理，不遮挡/改写宿主 DOM。素材导入、搜索、筛选、详情/删除与音频生成/配置原逻辑保留。
