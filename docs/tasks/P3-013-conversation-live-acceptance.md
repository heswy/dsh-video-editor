## 最小验收路径

1. 打开视频工作区，确认左侧只读预览、右侧原生对话/模型入口。首次自动打开/建立工程与会话不重复创建；记录专用 projectId/sessionId。沿用当前用户模型与权限，不改凭据/policy。
2. **第一条请求**：用一项普通创意生成短片，题材不限，不要求鹈鹕/球或固定模板。通过右侧真实 Composer 提交。观察 AI 经 video_engine 发布到绑定工程，左侧无需刷新、重开工程或手动更新就出现可播放画面。核对 published revision 与左侧 active revision；实际播放、暂停、seek。
3. **第二条请求**：自然语言修改该作品的一个可见内容或配色，保留其余内容。同一 projectId，revision 变化，左侧自动跟进且实际画面符合要求；不能用聊天文件卡、外部 PNG/MP4 或 shell 改工程替代。
4. **第三条请求**：再对同一作品修改一处，建议涉及横竖比例或时长以观察显示元数据。仍是同工程，自动更新并可播放；右侧模型说完成不作为证据。记录模型等待与“发布成功→左侧 ready”的耗时，避免混为渲染延迟。
5. 退出视频面板再返回/重新打开任务工程，不发额外模型请求，核对最后 revision 与作品仍在；用户原有工程保持不变。记录原生会话历史入口与模型选择入口可见即可，不另扩展审批/附件/全套主题/专业编辑验收。

若任一步失败：保留最后有效作品与错误，收集 Tool 请求/结果的必要脱敏字段、revision、路由/runtime 错误及安装身份；停止后续模型请求，不后台反复搜索仓库或 shell 修源，不把可恢复提示当作通过。发现功能缺陷则单独提交修复和新固定候选，不能修改运行中的已审 staging。
