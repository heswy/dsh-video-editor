# 1.0.0 导入视频预览与点击定位修复

2026-10-24 用户要求把实测问题写入方案、修复后自行安装最新版。基线origin/main 265167f；codex/timeline-media-polish。总方案见 docs/plans/V1.0-TIMELINE-VISUALIZATION.md，包含先前可视化布局、原声波形及拟议分离音频行为。本次修复证据只覆盖下列三项，不宣称尚未实现的缩略图/波形方案已经交付。

## 复现与修复

- 旧runtime在播放时偏移超过1/30秒就改currentTime，轻微解码延迟复现97次重复seek；长GOP视频易因重复解码定位无法持续呈现。改为合并显式跳转、metadata就绪后定位、seeked后只处理最新未完成目标；正常播放只校正明显漂移。复用原媒体/Range管线，不转码用户原素材。暂停、前后跳转、连续快速跳转、播放/暂停和销毁清理受回归保护。
- “开启声音/点击开启声音”改为“开启作品预览声音”，title说明是作品视频原声和音轨的预览，不改轨道静音/导出；保留浏览器用户手势激活兜底。
- 旧片段点击固定跳起点，空白轨道没有seek。现在按pointerdown时的稳定坐标定位并暂停播放；正常点击与拖动/trim区分，右键/标题/开关不误跳；空白点击按滚动/缩放坐标映射并按帧钳制。

## 验证

- 先在旧实现复现重复seek和片段点击12s未定位。真实Chrome+FFmpeg长GOP视频7项，随机/连续暂停跳转检查实际解码像素，轻微解码延迟播放seek写入降为1次。
- 同一测试只读加载用户导入的68秒H264视频，未修改或导出用户工程；检查解码帧时按完整源画面缩放，避免把宽视频左上黑边误判为黑屏。
