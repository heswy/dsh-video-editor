# V1 时间线可视化与分离音频

更新：2026-10-25。用户指派当前会话实施完整方案，并授权使用电脑安装、验收；允许AI调用分离操作，但本轮只保证用户手动流程，不评估AI目标理解/端到端效果。方案见 [V1.0-TIMELINE-VISUALIZATION](../plans/V1.0-TIMELINE-VISUALIZATION.md)。分支codex/timeline-media-polish，保留已安装810891c回滚。

## 实现范围

- 视频（含AI场景）连续真实缩略图，视频蓝色/音频绿色的顶部名称条；有原声的视频底部波形，无音频流不预留空带。画面关闭与声音静音分别表达，保留拖动、裁剪及播放头命中层级。
- 流式PCM解码为源时间峰值/RMS和多分辨率数据；双声道取最大绝对包络，防反相抵消。Canvas绘制可见窗口，有限显示增益不修改声音；裁剪、变速、淡化映射到源时间。
- 独立串行后台队列、request/status/cancel生命周期、revision迟到隔离、可见窗口优先、播放时取消采样、正式渲染优先；每请求最多4张128×72图及256波形桶，不把大图片塞入worker协议。AI场景一批复用浏览器页面，按自身时间定位；仅提供已验证快照资源，阻断外部网络。
- 内容哈希/源时间缓存、格式版本、原子写入、专用目录归属标记；每工程128MiB/已注册工程总512MiB预算，清理仅作用于本服务专用缓存。原素材、timeline及导出不受缓存影响。
- 右键视频“分离音频”：源视频原声关闭，音频在无冲突轨道对齐并自动选中/滚入视图；无合适轨道时新建，上限明确拒绝。直接引用原视频音频流，不复制大文件；独立的audioOnly片段继承源入点、时长、速度、音量、淡化及有效静音。sourceGainDb保存原轨道增益，避免分离时越过单推子范围或改变混音。一个事务、一次撤销/重做、正常revision/幂等和引用保护。
- 片段右键支持开关原声/片段声音。已分离的视频重新开启原声时提示叠加风险；删除音频不自动恢复原声。允许通过现有timeline.apply调用同一操作，未新增AI面板或供应商。
- 引擎client/worker能力对升级0.9.0，bundle仍1.0.0；新方法同步JSONL schema、README和固定打包版本对。
