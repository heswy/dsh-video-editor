# DSH Video 1.0.0

AI 对话创作与续改、即时预览、素材导入、多轨剪辑、真实波形与连续缩略图、分离音频、撤销重做、带声音 MP4 导出，以及用户主动插件更新。

## 环境

- DeepSeek Harness ≥ 0.2.1-rc.2
- Node.js ≥ 22、FFmpeg/ffprobe、Google Chrome
- 当前实测 macOS Apple Silicon

## 发行

包名：`dsh-video-editor`。GitHub 与 npm 安装运行相同的 JavaScript/引擎源码，不需要插件安装构建。macOS 离线包另含运行依赖。

正式发布前完成包内容检查、密钥扫描、临时 DSH_HOME 实装、工程恢复与真实渲染。发布后验证 npm 包名与 GitHub 公开提交两条下载链路。发布状态见 [STATUS](../STATUS.md)，操作见[发行指南](UPDATE-CHANNEL.md)。

## 已知边界

Windows/Linux/Intel 尚未完成实机验收；系统依赖不随插件附带。真实模型复杂续改效果和扬声器听感需要独立实机确认；代码生成音频不等于人声演唱。画布内对象编辑延期。
