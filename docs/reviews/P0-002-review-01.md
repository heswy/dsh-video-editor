## R1 [P2] main 尚未就绪时仍暴露模式入口

位置：`client.js:1006–1051`，尤其 `1029` 的 `isSlotDeclared(...) !== false` 分支。

真实 `slots.inject` 在 Slot 未声明时等待，而测试桩在未声明时直接抛错。当前代码当 main 未声明时跳过就绪检查，继续注册已经存在的 leading。于是普通界面出现“视频”按钮，但目标面板还不存在；`selectPanel` 失败后仅记日志，用户看不到有效结果。主声明折叠/重建同样需要协调入口是否可用，而不是仅在 apply 做一次预检。

要求：把入口可用性绑定到主面板实际注册的声明生命周期；尚未就绪时不显示可操作的死入口。main 恢复后再允许导航；注册失败或清理后及时撤回入口。每次重声明都重新检查 key 冲突，避免加载时的初始检查失效。

验证：修改测试桩以匹配已确认的真实契约，覆盖 main 延迟声明、声明后成功、折叠/重新声明、声明时注册失败与冲突，断言入口生命周期及清理。不要为迎合当前实现继续让 inject 把“等待”当错误。

## R2 [P2] 220ms 胶囊滑动在实际模式切换中没有起点

位置：`client.js:700–727`，配合 `.dv-mode[data-ready="false"]` 和两个独立挂载点。

现有选中位置直接取宿主 activePanel，这是正确的状态来源。但导航会卸载旧 ModeSwitch，新 ModeSwitch 以新 active 值直接挂载，同时 ready=false 禁用了 transition；下一帧只是打开 transition，位置没有变化。因而 CSS 声明了 220ms，真实普通↔视频切换却没有旧位置→新位置的滑动过程。当前 smoke 只断言选中属性，不能证明动效发生。

要求：为两个挂载点实现可中断的呈现连续性（可保留短暂的视觉过渡记录，不能以第二套 mode 布尔值替代宿主真相），或者实现等价、真实可发生且经评审认可的材质过渡。不能为了播放动画延迟真实导航，不能抢占宿主 root/overlay。快速反向切换和首次加载不能从错误选中态闪过。

验证：本地验证呈现起终态及中断逻辑，报告与真实画面验证的区别；安装授权后用真实页面短录屏确认。简化效果与 reduced-motion 下立即或轻量完成，不再播放固定的 repeat 动画。

## R3 [P2] 模式控件文字没有跟随宿主字号

位置：`client.js:157`、`458` 以及胶囊尺寸定义。

视频根使用了 `--dsh-content-font-size`，但模式按钮又被固定为 13px / 12.5px；普通模式胶囊在根外，也没有显式继承该变量。用户放大 DSH 字号后，最重要的导航文字仍然小，不能据根字号推定“跟随宿主字号”已实现。

要求：模式组件自身以宿主字号为基础按比例计算文字和必要空间，窄窗口优先折叠次要内容，不通过缩小导航文字补空间。保持安全 no-drag 与可点击区域；避免字号增大后按钮文字溢出。

验证：增加对应静态/逻辑约束即可，不建自制浏览器渲染器；真页面字号放大/窄窗口仍留在安装后的实测清单。
