## R1 [P2] 显示菜单缺少焦点进入与关闭回归

位置：`client.js:542–556` 及触发按钮/菜单项定义。当前打开只是 setMenuOpen；Escape 只是卸载菜单，既无菜单项/触发按钮 ref，也无移入/返回焦点逻辑。触发按钮声明 aria-haspopup=menu，子项声明 menuitemcheckbox，但仅添加角色不完成菜单键盘行为。

键盘打开后焦点仍留在触发按钮；Tab 进入选项再按 Escape 会移除被聚焦元素，源码没有恢复焦点的路径。后一项为基于实现的结构性判断，本轮未安装实测，不宣称有真页面复现。该问题影响任务要求的可访问菜单和可见焦点，不是视觉样式偏好。

修复可采用宿主受支持的菜单 primitive，或完整管理现有单项菜单：Enter/Space（可支持 ArrowDown）打开后聚焦项；Escape 关闭并回焦触发按钮；Tab 退出时不困住用户、不让焦点留在卸载节点；关闭/卸载清理监听。也可使用语义正确的原生 popover + checkbox 避免虚假的 menu 行为，但须保留轻量单一入口与键盘可达，不增加常驻说明。
