# 界面设计

左侧作品，右侧对话。中性工作面、细线图标、清楚的字体层级；色彩主要来自作品与轨道。浮层按需显示，不增加常驻场景卡片。

- 顶栏：返回、可重命名作品标题、工程切换、文件夹入口、插件更新与导出。
- 作品侧：素材入口、只读画布、播放/暂停、进度和时间码。
- 对话侧：宿主原生会话、引用、新会话和历史。宽屏默认约42%，可拖动分隔条，窄屏上下排列。
- 设置：对话侧顶栏齿轮入口，浮层分「音乐模型」「系统提示词」两页签；模型行显示协议/默认/密钥状态（不回显 Key），支持添加、编辑、测试连接、设为默认与两步确认删除；表单协议下拉覆盖六种协议，切换时自动带出该厂商默认 Base URL 与远端模型 ID（未手改的字段才跟随），并显示该厂商的时长/计费提示；提示词页签为追加文本域加计数、保存与恢复默认。设置浮层与框选条全部使用面板自身的 `--dv-panel-line`/`--dv-panel-ink` 与 `--dsw-alias-bg-base` 变量（含 `select option`），不得引用浅色主题 token，宿主暗色下不得出现白底回显。
- 时间线：默认适应工程宽度；视频蓝色、音频绿色；连续缩略图与真实波形。分离原声后视频隐藏波形，独立音轨保留波形。
- 框选配乐：工具栏开关进入框选模式，ruler 拖动选精确范围（半透明跨轨选区与起止时间），选区条支持秒输入、清除、复制引用、剧情描述输入与发送到聊天；发送走 Host 的公开会话受理通道（UI-only `session.send`，请求 ID 去重，失败只如实报"状态未知"不静默重发），空描述时按钮禁用；当前选区同时注册为原生 `@`「当前时间范围」候选，工程切换或 revision 变化即失效。
- 轨道栏：156px，显示名称及画面/声音开关；音频轨无画面开关。播放头和拖动坐标共用同一栏宽。
- 菜单：靠近点击位置，边缘自动避让；点击外部或 Esc 关闭，执行有效动作后关闭。非空轨道删除需确认。
- 详细参数和修改历史按需展开；生成的音频直接进入时间线，用户上传进入素材。
- 加载、失败、取消、冲突与重试均给出明确状态；预览刷新期间保留上一有效画面。

系统主题、减少动态效果、键盘焦点和可访问标签必须保留。功能范围见 [PRODUCT](../product/PRODUCT.md)。
